# Política de Privacidad

**Última actualización:** 12 de octubre de 2026

Esta Política de Privacidad describe qué datos recopila **Harin Bot** (en adelante, "el Bot"), cómo los usa y qué control tienes sobre ellos.

## 1. Datos que recopilamos

Para proporcionar sus funcionalidades, el Bot almacena los siguientes datos:

**Datos de usuario:**
- ID de usuario de Discord
- Nombre de usuario y avatar (solo para mostrar en comandos como `profile`, `rank` o `userinfo`)
- Monedas virtuales, inventario, niveles y experiencia dentro del Bot
- Advertencias (warns) registradas por moderadores
- Cooldowns de economía y de comandos

**Datos de servidor:**
- ID del servidor (guild)
- Configuraciones de niveles, tienda y sistema de advertencias
- Canales de registro de moderación (modlog)
- Datos de giveaways (mensaje, canal, participantes, ganador)
- Registros de moderación (bans, kicks, timeouts, warns)

**Datos de mensajes:**
- El Bot puede leer el contenido de los mensajes únicamente para ejecutar comandos de prefijo y para el sistema de niveles (contar mensajes). No se almacena el contenido de los mensajes de forma permanente.

## 2. Cómo usamos los datos

Los datos se usan exclusivamente para:

- Proporcionar la funcionalidad del Bot (economía, niveles, moderación, giveaways, etc.)
- Mantener la configuración de cada servidor
- Registrar acciones de moderación para consulta posterior
- Prevenir abusos y aplicar cooldowns

No usamos los datos para publicidad, perfilado comercial ni venta a terceros.

## 3. Dónde se almacenan

**Harin Bot** utiliza **MongoDB Atlas** como servicio de base de datos en la nube para almacenar la información descrita en esta política. MongoDB Atlas es un servicio de terceros proporcionado por MongoDB, Inc., que aloja los datos en servidores seguros.

Los datos no se envían a servicios externos distintos de:
- **MongoDB Atlas**, utilizado exclusivamente como almacenamiento de datos del Bot.
- **La API de Discord**, necesaria para el funcionamiento del Bot.

No se comparten datos con terceros con fines publicitarios ni comerciales.

## 4. Cuánto tiempo se conservan

- **Datos de usuario**: mientras el Bot esté en el servidor y el usuario siga participando.
- **Datos de servidor**: mientras el Bot permanezca en el servidor.
- **Registros de moderación**: hasta que un administrador los elimine o el Bot sea expulsado.
- **Giveaways finalizados**: hasta 30 días después de su finalización, salvo que se eliminen manualmente.

## 5. Compartición de datos

No compartimos datos con terceros, salvo obligación legal o requerimiento de Discord.

## 6. Eliminación de datos

Puedes solicitar la eliminación de tus datos contactando a través de nuestro servidor de soporte: [https://discord.gg/yXWedmuSxE](https://discord.gg/yXWedmuSxE).

Si eres administrador, también puedes expulsar a **Harin Bot** del servidor, lo que eliminará los datos asociados a ese servidor.

## 7. Menores de edad

**Harin Bot** no está dirigido a menores de 13 años (o la edad mínima legal en tu país). No recopilamos conscientemente datos de menores.

## 8. Cambios en esta política

Podemos actualizar esta Política de Privacidad en cualquier momento. Los cambios se publican en esta misma página.
